Project Overview

Polines Career Center - Web-Based Job Portal System Polines Career Center is a web-based career portal developed to connect alumni, students, the general public, and partner companies (mitra) with job opportunities in an efficient and structured way. The system also supports administrators in managing job postings, partners, and premium services.

Key Features

🔐 Authentication & User Roles Multi-role authentication system: Admin, Student, Alumni, and Public Users Separate registration forms for students and general users Secure login using email and password Role-based access control for different dashboards and features

👤 User Profile Management Users can manage personal profiles including education background and interests Profile data is used to support job recommendation features Alumni and students can update graduation year, major, and GPA.

💼 Job Vacancy Management Job listings displayed in an attractive card-based layout Each job includes details such as company, location, salary, work type, and publication date Job data is categorized by major/department Support for CRUD (Create, Read, Update, Delete) job postings

⭐ Saved Jobs (Favorites) Users can save or bookmark job vacancies Saved jobs are stored in “Saved Jobs” page for easy access Helps users track vacancies they are interested in

🔎 Search & Filtering System Search jobs by title or company name Filter jobs based on location, job type, and department Improves job discovery and user experience

🧠 Job Recommendation System Job recommendations based on user profile data Matching system considers major, interests, and graduation year Designed to help users find relevant job opportunities faster

🏢 Partner (Mitra) Management Admin can approve and manage partner companies Each partner has its own job postings and profile Job listings are associated with specific partners

💳 Premium Package & Payment System Partners can purchase job posting packages Integrated with Midtrans payment gateway Automatic package activation after successful payment Purchase history and package usage tracking

📢 Banner & Announcement Management Admin can manage promotional banners on the homepage Supports image upload, description, status, and display order Used for announcements and featured job promotions

📊 Admin Dashboard Centralized dashboard for system monitoring Manage users, job vacancies, partners, banners, and packages View transaction and posting statistics

📱 Responsive & Modern UI Built using Laravel Blade, TailwindCSS, and Bootstrap Responsive design for desktop and mobile devices Smooth animations and clean interface for better UX

🔐 Security & Data Management Form validation and protected routes Secure data storage with relational database Role-based middleware to prevent unauthorized access

Tech Stack: Laravel, PHP, MySQL, Blade Template, Bootstrap
