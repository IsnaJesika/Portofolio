Smart Attendance System

Full Stack Web
PHP & MySQL
Multi-Role System

Project Introduction

This project is a development of a dynamic attendance website designed to facilitate the process of recording student and lecturer attendance. The website was built using PHP as the main programming language and MySQL as the database management system.

The system provides a comprehensive solution for educational institutions to efficiently manage attendance records, generate reports, and maintain accurate data for academic purposes.

Key Features

Dual-Role Authentication System

  • Lecturer Access: Lecturers can log into the system to manage attendance records
  • Student Access: Students can log in to record their attendance for classes

Student Attendance Recording

  • Students log in by entering their password and course code
  • Upon successful submission, a pop-up notification confirms the attendance has been recorded
  • Real-time validation ensures accurate data entry

Lecturer Management Dashboard

  • View comprehensive attendance recapitulation for all students
  • Edit attendance records when corrections are needed
  • Delete incorrect or duplicate entries
  • Add manual attendance entries for special circumstances

Security & Authentication

  • Secure authentication mechanism ensures only authorized users can access features
  • Role-based access control (RBAC) restricts functionality based on user type
  • Password encryption for data security

Reporting & Analytics

  • Generate attendance reports accessible to lecturers
  • Download reports in various formats for further analysis
  • Statistical overview of attendance patterns

Technology Stack

  • PHP: Backend development and application logic
  • MySQL: Database storage and attendance data management
  • HTML/CSS/JavaScript: Frontend development ensuring responsive and intuitive user interface

Project Goals

This project aims to improve efficiency and accuracy in attendance recording within academic environments. It provides convenience for students to record their attendance while offering lecturers effective tools to manage and monitor student attendance comprehensively.
